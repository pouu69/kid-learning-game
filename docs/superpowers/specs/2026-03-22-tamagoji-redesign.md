# 타마고지 전면 재설계 — 교육용 한글 다마고치

## 개요

타마고지를 5~7세 대상 한글 교육용 다마고치로 전면 재설계한다.

- **타겟**: 5~7세 아동
- **목적**: 자음/모음 인식 + 글자 조합 학습
- **핵심 컨셉**: "말 배우는 펫" — 아이가 한글을 가르치면 펫이 점점 말을 배워감
- **디바이스**: 아이패드 브라우저 (가로/세로 대응)
- **기술 스택**: PixiJS + PWA + localStorage (유지)
- **디자인**: 그림책 스타일, 차분하되 풍성한 색감

---

## 1. 핵심 루프

학습이 의무가 아닌 "펫 돌봄"의 일부로 자연스럽게 녹아드는 구조.

```
글자 가르치기(학습) → 펫이 말을 배움(대화) → 배운 말로 요청(돌봄) → 새 활동 해금 → 반복
```

### 기존 vs 새 루프

| 기존 (단순 관리) | 새 루프 (학습=성장) |
|---|---|
| 스탯 떨어짐 → 버튼 누름 → 스탯 올라감 | 글자 가르침 → 펫이 말함 → 새 활동 생김 |
| 학습 = 미니게임 중 하나 | 학습 = 게임의 핵심 엔진 |
| 동기 = 스탯 유지 의무감 | 동기 = "펫이 뭐라고 할까?" 호기심 |

### 설계 원칙

- **학습이 의무가 아닌 "먹이"** — 글자를 안 가르치면 펫이 배고파하지만, 벌은 없음
- **펫의 언어 = 진행도** — 레벨 숫자 대신 펫이 할 수 있는 말이 많아지는 것 자체가 성장
- **실패 없는 학습** — 5~7세에게 "틀렸어"는 없음. 정답/오답 개념 자체가 거의 없음
- **짧은 세션도 의미 있게** — 1분만 열어도 펫이 배운 말로 인사

## 2. 한글 학습 시스템

### 방법론 근거

3가지 검증된 유아 한글 교육 방법론을 결합:

1. **통글자 → 분해 (Top-Down)**
   - 근거: 한국 유치원 누리과정, 문해력 연구
   - 아이는 "맘마"라는 의미 있는 단어를 먼저 통째로 인식한 다음, 그 안에서 글자를 발견

2. **다감각 학습 (Multisensory)**
   - 근거: 몬테소리 교육법, 오턴-길링엄 방법론
   - 글자를 보고(시각) + 듣고(청각) + 만지며(촉각) 동시에 경험

3. **맥락 중심 반복 (Contextual Repetition)**
   - 근거: 간격 반복(Spaced Repetition), 상황 학습 이론
   - "ㅁ 복습"이 아니라 새 단어 "물"에서 ㅁ을 다시 만남

### 4단계 학습 사이클

하나의 단어를 배우는 전체 과정. 며칠에 걸쳐 진행.

#### 1단계: 만남 — 단어를 통째로 경험

- 펫이 뭔가를 원함 (배고프면 밥 그림 떠오름)
- 화면에 크게 "맘마" 나타남 + 자동 발음 재생 + 삽화
- "같이 말해볼까?" — 아이가 따라 말하기 유도 (음성 인식 안 함, 유도만)
- "맘마" 글자를 터치하면 펫에게 날아감 → 펫이 밥 먹음
- 교육적 의미: 글자 = 의미라는 연결을 체감

#### 2단계: 발견 — 단어 안의 글자를 탐구

- "맘마"가 천천히 분리되는 애니메이션: 맘마 → 맘 마 → ㅁ ㅏ ㅁ ㅁ ㅏ
- 각 조각 분리 시 해당 소리 재생
- 분리된 글자를 자유롭게 터치 → 소리 듣기 (정답/오답 없음)
- 글자 따라 그리기: 큰 점선 가이드 위를 손가락으로. 그리는 동안 소리 재생
- 교육적 의미: 통글자 안에서 낱글자를 발견. 추상 부호가 아닌 "아는 말의 일부"

#### 3단계: 놀이 — 조각으로 놀기

- **퍼즐 맞추기**: 흩어진 ㅁ, ㅏ 조각을 원래 자리에 끌어놓기. 자석 스냅. 완성되면 "맘마!" 소리 + 펫 반응
- **색칠하기**: 큰 글자 윤곽선 안을 손가락으로 칠하기. 다 칠하면 글자가 살아남
- **소리 매칭**: 2~3개 글자 중 소리에 맞는 글자 터치. 이미 2단계에서 충분히 익힌 후에만 등장
- 교육적 의미: 소리 매칭이 기존 "듣고 고르기"와 비슷하지만, 이미 아는 상태에서 확인하는 것

#### 4단계: 재회 — 다른 단어에서 다시 만남

- 다음 단어 "물"의 1단계(만남) 시작
- "물"이 쪼개지면 → ㅁ 발견! "맘마에서 본 거다!" → 하이라이트 + 펫 반응
- 아는 글자는 빠르게 확인, 모르는 글자만 2~3단계 반복
- 교육적 의미: 드릴이 아닌 자연 반복. "아 이거 아는 거다!"라는 성취감

### 데일리 흐름

- 하루에 단어 1~2개. 4단계를 한 세션 안에서 다 할 수도, 며칠에 걸쳐 할 수도
- 기본 활동 3개 + 전부 하면 보너스 1~2개 (펫이 "하나 더 해볼까?" 제안)
- 목록에서 고르는 방식이 아님. 펫이 시간에 따라 다른 것을 원함 → 자연스러운 노출
  - 아침에 열면: 펫이 배고파 → 밥 주기(만남 활동)
  - 밥 주고 나면: 놀고 싶어 → 놀기(발견/놀이 활동)
  - 다 하면: "고마워~" + 자유 놀이
- 다음 날 새 콘텐츠. 안 한 것도 압박 없이 리셋

### 인터랙션 설계

#### 터치 UX (아이패드)

- 모든 버튼 최소 48x48pt, 글자 선택 60x60pt 이상
- 버튼 간 간격 최소 12pt
- 뒤로가기/나가기는 구석에 작게
- 부모 메뉴는 3초 길게 누르기
- 멀티터치 무시 (손바닥 실수 방지)
- 학습 중 홈 실수 → 자동 저장

#### 글자 인식 (따라 그리기)

- AI 필기 인식 안 씀
- 큰 점선 가이드 + 획순 화살표 애니메이션
- 판정: 가이드 점들의 70%를 지나갔는가
- 못 그려도 무한 재시도. "잘했어/못했어" 판정 없음

#### 소리 설계

- 음성 인식 OFF — 5세 발음 인식은 기술적으로 불안정. 인식 실패 = 학습 좌절
- 음성 재생 ON — Web Speech API (ko-KR) 또는 녹음된 음성 파일
- 모든 글자 터치 시 자동 발음 재생

## 3. 초기 커리큘럼 (20단어)

### 단어 선정 원칙

1. 아이가 이미 말로 아는 단어 — 의미를 설명할 필요 없는 것
2. 새 글자는 한 번에 1~2개만 — 나머지는 복습 글자로 채움
3. 점점 아는 글자로만 된 단어가 등장 → "나 이거 다 읽을 수 있어!"
4. 입술소리(ㅁ,ㅂ) → 혀끝소리(ㄴ,ㄷ,ㄹ) → 잇소리(ㅅ,ㅈ) — 발음 발달 순서 반영

### 미학습 글자 처리 (ㅇ 등)

"아빠"(단어 7)에 ㅇ이 포함되지만, ㅇ의 정식 학습은 "아이"(단어 12)에서 진행. 이처럼 아직 정식으로 배우지 않은 글자가 단어에 포함될 때의 처리:

- **만남(1단계)**: 단어를 통째로 보여줌. 미학습 글자도 자연스럽게 포함
- **발견(2단계)**: 분해 시 미학습 글자는 회색으로 표시 + "이건 나중에 배울 거야~" 안내. 따라 그리기/터치 탐구 대상에서 제외
- **놀이(3단계)**: 퍼즐/매칭에서 미학습 글자는 고정된 조각으로 이미 놓여 있음 (아이가 배치할 필요 없음)
- **knownLetters에 추가 안 됨** — 정식 학습 단어에서 4단계를 완료해야 습득 처리

이 방식으로 ㅇ 같은 글자에 미리 자연스럽게 노출되되, 정식 학습은 해당 단어 차례에 진행.

### 학습 통계 (20단어 완료 시)

| 항목 | 수량 |
|------|------|
| 기본 자음 습득 | 8개 (ㅁ ㄹ ㄴ ㄷ ㅂ ㅅ ㅇ ㅈ). ㄱ은 21번째 단어 이후 |
| 기본 모음 습득 | 6개 (ㅏ ㅓ ㅗ ㅜ ㅡ ㅣ). 복합모음은 21번째 단어 이후 |
| 글자 조합 경험 | 40+ (단어별 음절 수 합계) |
| 자연 복습 횟수 | 글자당 평균 5~8회 재회 |
| 예상 소요 기간 | 4~8주 (하루 10~15분 기준) |

## 4. 펫 시스템

### 성장 8단계

진화 조건 = 완료한 단어 수.

| 단계 | 이름 | 단어 수 | 펫이 할 수 있는 말 | 해금 |
|------|------|---------|-------------------|------|
| 0 | 알 | 0 | 없음 | 터치(쓰다듬기) |
| 1 | 갓 태어남 | 1 | "맘마~" | 밥 주기 |
| 2 | 아기 | 3 | "나!", "물~" | 따라 그리기 학습 |
| 3 | 호기심쟁이 | 5 | "머리", "다리" | 놀기 |
| 4 | 말하기 시작 | 8 | "바나나!", "아빠" | 퍼즐 놀이 |
| 5 | 수다쟁이 | 12 | "손!", "아이" | 색칠하기 |
| 6 | 글자 요리사 | 18 | "주스 줘~", "모자!" | 조합 블록 |
| 7 | 다 큰 펫 | 25 | "버스 타고 바다 가자!" | 자유 모드 |

> 초기 커리큘럼(20단어)으로는 6단계(18단어)까지 도달 가능. 7단계(25단어)는 커리큘럼 확장 후 도달.

### 스탯 (3개)

기존 4개(배고픔/기분/에너지/청결)에서 3개로 단순화.

| 스탯 | 감소 속도 | 회복 방법 | 표시 방식 |
|------|-----------|-----------|-----------|
| 배고픔 | 0.3/초 (깨어있을 때) | 학습(만남) 완료 → +25 | ♥ + 미니바 |
| 기분 | 0.2/초 | 학습(놀이) 완료 → +15, 터치 → +5 | ☺ + 미니바 |
| 졸림 | +0.15/초 (깨어있을 때), -1.5/초 (잠잘 때) | 재우기 | ☽ + 미니바 |

- 청결 스탯: 삭제 (교육 루프에 불필요)
- 에너지 → 졸림: 반전 ("에너지"는 추상적, "졸려~"는 5세도 이해)
- 숫자 표시 없음. 바의 양과 펫 표정으로만 전달
- 죽음 없음. 스탯이 0이 되면 펫이 슬퍼하거나 잠들 뿐

### 감정 표현

스탯 바 대신 펫이 직접 상태를 말과 행동으로 보여줌.

| 상태 | 행동 | 말풍선 | 학습 연결 |
|------|------|--------|-----------|
| 행복 | 깡충깡충, 빙글빙글 | 배운 말 중 랜덤 | "더 가르치면 더 많이 말할 거야" |
| 배고픔 | 느릿느릿, 배 만짐 | "맘마..." (배웠다면) | 밥 주기 = 만남 활동 |
| 졸림 | 하품, 눈 감김 | "자..." 또는 "zzz" | 재우기 = 학습 없이 (쉬는 시간) |
| 말 못할 때 | 같지만 말풍선 대신 "...", "??" | — | "글자를 가르쳐주면 뭐라고 할까?" |

## 5. UI 설계

### 세계관: 펫의 마당

빈 화면에 펫이 떠 있는 게 아니라, 펫이 사는 "마당"이 있음.

- **하늘 + 잔디 언덕** — 시간에 따라 변함 (낮: 파란 하늘/저녁: 노을/밤: 별+달)
- **랜덤 날씨** — 맑음, 구름, 비 등
- **배운 글자 = 글자꽃** — 잔디에 둥근 꽃처럼 피어남. 터치하면 발음 재생. 잠긴 글자는 회색 "?"
- **펫이 중앙에서 살아 움직임** — 눈 깜빡, 좌우 두리번, 가끔 점프

### 화면 구조 (3개)

메뉴에서 고르기 패턴 없음. 펫과의 대화 흐름이 곧 네비게이션.

#### 화면 1: 펫과 함께 (홈)

- 화면의 80%가 펫 + 마당
- 상단: 이름/단계 (좌), 스탯 미니 아이콘 (우) — 글라스모피즘으로 배경 위에 부드럽게
- 중앙: 펫 + 말풍선
- 하단: 펫 상태에 따라 **단일 버튼** (배고프면 "밥 주기", 심심하면 "같이 놀기", 졸리면 "재우기", 괜찮으면 버튼 없음)
- 펫 터치 = 쓰다듬기 (기분 +5)

#### 화면 2: 같이 해결하기 (학습)

- "학습" 화면이 아님. "펫이 원하는 걸 같이 해결하는" 화면
- 상단: 돌아가기 + 진행 도트
- 펫이 위에서 응원 + 말풍선으로 상황 설명
- 중앙: 학습 활동 (단계에 따라 다름)
- 하단: 응원 텍스트

#### 화면 3: 펫의 반응 (보상)

- 별도 "클리어" 화면 없음. 학습 화면에서 바로 전환
- 펫이 ^_^ 표정으로 점프 + 별 반짝이 + 새 말을 함
- 홈으로 자연스럽게 돌아감 → 마당에 새 글자꽃이 피어나 있음

### 보상 3단계

1. **즉각 반응** — 맞는 글자 터치 → 글자가 커지며 반짝 + 정답 소리
2. **펫 반응** — ^_^ 표정 + 점프 + 새 말
3. **마당 변화** — 홈에 새 글자꽃 추가. "내가 한 일이 세상을 바꿨다"

### 색감 팔레트: 그림책 스타일

자극을 줄이면서도 따뜻한 공간감. 자연물/음식에서 가져온 톤.

| 이름 | 색상 | 용도 |
|------|------|------|
| 크림 | #fdf8f0 | 학습 화면 배경 |
| 풀잎 | #a8d8b0 | 잔디, 성공 |
| 하늘 | #88c8e8 | 낮 배경 |
| 귤 | #f4b870 | 강조, 버튼 |
| 딸기 | #f08080 | 하트, 배고픔 |
| 포도 | #c8a0d8 | 밤, 졸림 |
| 별 | #f0d060 | 보상, 반짝이 |
| 쿠키 | #e8c8a0 | 땅, UI 요소 |
| 초콜릿 | #3a3028 | 텍스트 |
| 우유 | #ffffff | 카드, 말풍선 |

### 레이아웃 원칙

- 스크롤 최소화 — 각 화면이 뷰포트에 맞게
- 하단에 주요 액션 — 아이패드 잡고 있을 때 엄지 닿는 위치
- 화면 전환은 슬라이드 — 부드러운 좌우 전환
- 항상 펫이 보임 — 학습 중에도 작은 펫이 응원
- 가로/세로 모두 대응 — CSS 미디어 쿼리 + PixiJS resize

## 7. 기술 아키텍처

### 유지

| 기술 | 용도 |
|------|------|
| PixiJS | 펫 렌더링, 애니메이션, 글자꽃 마당, 파티클 |
| PWA | Service Worker + manifest. 오프라인 플레이 |
| localStorage | 게임 상태 + 학습 데이터 영속 저장 |
| Vanilla JS | 프레임워크 없이, 번들러 없이 |

### 추가

| 기술 | 용도 |
|------|------|
| Web Speech API (TTS) | 글자/단어 발음. ko-KR. 대안: 녹음 음성 파일 |
| 터치 캔버스 | 따라 그리기/색칠하기. PixiJS Graphics |
| 드래그 앤 드롭 | 퍼즐 조각. PixiJS 인터랙션. 스냅 60pt 반경 |
| 일러스트 에셋 | 단어별 삽화. SVG 또는 스프라이트 |

### 성능/제약

| 항목 | 설계 |
|------|------|
