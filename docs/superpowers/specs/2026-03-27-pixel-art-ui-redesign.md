# Tamagoji UI Redesign: Pixel Art Style

**Date:** 2026-03-27
**Status:** Approved (Rev 2)

## Overview

Tamagoji의 전체 UI를 픽셀 아트 스타일로 리디자인한다. 5~6세 비문해 아동이 텍스트 없이도 직관적으로 사용할 수 있는 시각적 UX 패턴을 도입하고, 펫의 과장된 행동으로 다음 행동을 유도한다.

**핵심 변경 사항:**
- 그림책/글래스모피즘 스타일 → 픽셀 아트 게임 스타일
- 낮/밤 배경 전환 (오후 7시 기준)
- 아이콘 중심 UI + 펫 행동 유도 (비문해 UX)
- 하이브리드 네비게이션 (돌봄=홈에서 즉시, 학습=별도 공간)

**스코프 경계:**
- 이 스펙은 비주얼 리디자인 + UX 개선에 집중
- 게임 메카닉 (스탯 수, 진화 단계 수, 학습 커리큘럼)은 기존 코드 유지
- 새로운 스탯이나 진화 단계를 추가하지 않음

**낮/밤 전환:**
- 기준: `new Date().getHours()` — 7 이상 19 미만이면 낮, 그 외 밤
- 기존 일몰(sunset) 모드 제거 — 낮/밤 2단계만 유지
- 전환은 색상값 그라데이션 보간으로 부드럽게 (약 2초)
- `world.js`의 기존 시간 로직(`updateTimeOfDay()`)을 수정

### Typography

- 픽셀 한글 폰트: **DungGeunMo** (둥근모꼴, 무료 웹폰트)
  - CDN: `https://cdn.jsdelivr.net/npm/dunggeunmo-font`
  - 기존 Gaegu/Noto Sans KR 대체
- 텍스트는 보조적 역할 — 아이콘/색상이 주요 정보 전달

### Pixel Art Rules

- 캐릭터/오브젝트: 두꺼운 테두리 (3-4px), 내부 하이라이트, 볼 블러시
- 버튼: 3D 눌림 효과 (`box-shadow: 0 3px 0`), 누르면 그림자 사라짐
- 월드 오브젝트: 나무, 꽃, 울타리, 버섯, 한글 꽃잎 — 모두 픽셀 블록 스타일

### Asset Strategy

- **렌더링 방식: PixiJS Graphics API (프로시저럴)** — 기존 방식 유지
  - 스프라이트시트 없이 코드로 픽셀 아트를 그림
  - `renderer.js`의 `buildPet()` / `_drawBody()`, `world.js`의 월드 오브젝트 그리기 함수를 픽셀 스타일로 수정
  - 장점: 별도 에셋 파일 불필요, 동적 색상 변경 용이 (진화 단계별), 로딩 없음
- **픽셀 느낌 구현**: Graphics API로 사각형 블록을 조합하여 캐릭터/오브젝트 형태 구성
  - `PIXI.Graphics`의 `rect()`, `roundRect()` 조합
  - 테두리: `stroke()` 또는 약간 큰 배경 사각형 위에 내부 사각형 겹치기

## 2. Home Screen

### Layout

| 영역 | 내용 | 비율 |
|------|------|------|
| HUD | 이름 뱃지 (좌상) + 스탯 바 3개 (우상) | ~10% |
| World | 하늘 + 잔디, 펫이 돌아다님, 배경 오브젝트 | ~70% |
| Care Bar | 4개 버튼 (밥/잠/씻기/배우기) | ~20% |

### HUD

- **이름 뱃지** (좌상): 어두운 배경 + 금색 테두리, 별 아이콘 + 펫 이름 + 레벨
- **스탯 바** (우상): 3개 가로 바 (배고픔/기분/졸림), 각각 색상 코딩 + 아이콘
  - 바 내부에 하이라이트 광택 효과 (상단 3px 밝은 색)
  - 스탯 낮으면 바가 깜빡임
- **터치 타겟**: 모든 HUD 요소 최소 44pt (iPad 접근성 기준)

### World Details

- 나무: 삼각 픽셀 나뭇잎 + 사각 줄기
- 꽃: 색상별 픽셀 꽃 (빨강, 노랑, 보라)
- 한글 꽃잎: 배운 글자가 꽃 위에 표시 (추가 학습 게임 연결)
- 울타리: 나무 색상 픽셀 울타리 (우측)
- 버섯: 빨간 점 무늬 버섯
- 풀밭 디테일: 상단 가장자리에 풀 터프트
- 낮: 구름 (다중 블록), 태양 (광선), 새 (V 모양)
- 밤: 별 (다양한 크기/밝기), 초승달 (글로우), 반딧불이 (발광 효과), 나무 실루엣
- **빈 상태**: 아직 글자를 안 배웠으면 한글 꽃잎 없이 일반 꽃만 표시

### Pet System

**기본 행동:**
- 좌우 워킹 (idle 상태에서 지속적으로 걸어다님)
- 간헐적 점프 (랜덤 간격)
- 깜빡임 (랜덤 타이밍)
- 물리엔진 기반 드래그 앤 드롭 유지 (기존 `renderer.js` 모멘텀/바운스 로직)
- 탭 시 파티클 이펙트 (별/하트/반짝이)

**성장 — 기존 6단계 유지, 픽셀 아트로 리스킨:**

기존 `EVOLUTION` 배열 (`curriculum.js`) 및 `PET_STAGES` (`sprites.js`)의 구조 유지. 진화 조건(`Pet.checkEvolution()`)도 변경 없음. 시각적 외형만 픽셀 스타일로 재구현.

| 단계 | 기존 이름 | 픽셀 아트 외형 |
|------|-----------|----------------|
| 0 | 알 | 크림색 픽셀 알, 통통 튀는 idle |
| 1 | 갓 태어남 | 연한 노랑 블롭, 눈만, 작은 크기 |
| 2 | 호기심쟁이 | 피치색, 귀 + 발 추가 |
| 3 | 말하기 시작 | 주황색, 입 표현 추가 |
| 4 | 수다쟁이 | 코랄색, 팔 추가 |
| 5 | 다 큰 펫 | 하늘색, 날개 추가, 가장 큰 크기 |

각 단계의 기본색/크기/파츠는 기존 `sprites.js`의 `PET_STAGES`에서 정의된 값을 따르되, 렌더링을 픽셀 블록 스타일로 변경.

## 3. Non-Literate UX (5-6세 비문해 패턴)

### Icon-First UI (B 패턴)

- 모든 버튼은 아이콘이 주요 정보 전달, 텍스트는 보조 (DungGeunMo 폰트, 작은 크기)
- 아이콘은 기능을 직관적으로 나타내는 픽셀 그래픽
- 부모가 처음 한 번 알려주면 이후 아이콘만으로 인식 가능
- 버튼 터치 타겟: 최소 56px (아이 손가락 고려)

### Pet-Driven Navigation (D 패턴)

펫의 과장된 행동으로 아이가 다음 행동을 인식. 기존 3개 스탯(hunger, mood, sleepy)에 매핑:

| 상태 | 스탯 조건 | 펫 행동 | 시각 효과 |
|------|-----------|---------|-----------|
| 배고픔 | hunger < 30 | 배를 잡고 흔들흔들 + 바닥에 드러누움 | 빈 밥그릇이 펫 머리 위에 떠다님 |
| 졸림 | sleepy > 80 | 몸이 앞뒤로 꾸벅꾸벅 + 넘어질 듯 비틀거림 | 큰 Z 글자가 연속으로 올라감 |
| 기분 나쁨 | mood < 40 | 구석에 쪼그려 앉음 + 등 돌림 | 먹구름이 펫 머리 위에 생김 |

**씻기**: 별도 스탯 없음. 기존 로직 유지 — 씻기 미니게임 완료 시 `mood += 15`. 씻기 버튼은 항상 사용 가능하며, 기분이 낮을 때 기분 나쁨 행동과 함께 씻기 버튼도 반짝여서 "씻기로도 기분을 올릴 수 있다"는 것을 보여줌.

**펫이 버튼 방향을 가리키는 방식:**
- 펫 스프라이트가 해당 버튼이 있는 방향(하단)을 바라봄 (고개를 아래로)
- 해당 버튼 위로 작은 화살표 픽셀 아이콘이 깜빡임
- 펫 머리 위 떠다니는 아이콘(밥그릇/Z/먹구름)이 버튼의 아이콘과 같은 모양으로 매칭

**추가 시각 단서:**
- 상태가 심각하면 (hunger < 15, mood < 20, sleepy > 90) 화면 전체가 살짝 흔들림 + 버튼이 커졌다 작아졌다 반복
- 아이가 올바른 버튼을 누르면 환호 이펙트 (별 폭발 + 펫 점프)

## 4. Care System UI

### Care Bar Buttons

| 버튼 | 아이콘 | 색상 | 미니게임 |
|------|--------|------|----------|
| 밥 | 밥그릇 픽셀 아이콘 | 빨강 `#f86868` | 음식 선택 → 떨어짐 → 펫 냠냠 |
| 잠 | 초승달 픽셀 아이콘 | 보라 `#a888d0` | 별 5개 탭 (자장가) → 펫 잠듦 |
| 씻기 | 물방울 픽셀 아이콘 | 파랑 `#58b8f8` | 펫 위 문지르기 → 거품 → 반짝 → mood +15 |
| 배우기 | 한글 "ㄱ" 픽셀 아이콘 | 금색 `#f8d848` | 학습 공간으로 이동 |

### Button Interaction

- **평상시:** 3D 눌림 그림자 (`box-shadow: 0 3px 0`), 아이콘만으로 인식 가능
- **스탯 낮을 때:** 버튼이 위아래로 통통 바운스 + `!` 뱃지
- **누를 때:** 그림자 사라지며 눌리는 느낌 + 짧은 효과음
- **완료 후:** 펫이 기뻐 뛰며 별 파티클 + 스탯 바 차오르는 애니메이션

### Care → Learning Connection

- 밥 주기 완료 후 펫이 기분 좋아하며 학습 버튼 방향을 바라봄
- 자연스러운 학습 유도 (강제 아님 — 바라보는 정도, 3초 후 일반 idle로 복귀)

## 5. Learning Screen

### Rendering Approach

**학습 화면은 DOM 기반 유지, 픽셀 CSS 스킨 적용.**
- 기존 `Learning.openPopup()` DOM 구조 유지
- CSS를 픽셀 아트 스타일로 전면 교체 (DungGeunMo 폰트, 픽셀 테두리, 게임 컬러)
- 이유: 한글 텍스트 렌더링은 DOM이 안정적, Canvas 위 한글은 폰트 로딩/크기/줄바꿈 문제 발생 가능
- PixiJS는 홈 월드 전용, 학습 화면은 DOM 전용으로 명확히 분리

### Entry Transition

- 배우기 버튼 탭 → 펫이 오른쪽으로 걸어나감 (PixiJS 애니메이션)
- 픽셀 와이프 전환 (CSS 애니메이션: 블록이 화면을 채웠다 사라짐)
- 학습 화면 등장: DOM 기반, 배경은 교실 느낌의 CSS 그라데이션 + 픽셀 테두리

### Learning Activities (DOM Popup)

| 단계 | 활동 | 시각 표현 |
|------|------|-----------|
| 만나기 | 글자 등장 + 발음 + 뜻 | 큰 글자 표시 (DungGeunMo, 72px+), 배경색 강조 |
| 따라쓰기 | 점선 따라 손가락으로 쓰기 | Canvas 트레이싱 (기존 구조 유지), 픽셀 스타일 가이드 |
| 퍼즐 | 자음+모음 블록 조합 | 픽셀 블록 CSS, 드래그 → 슬롯에 끼우기 |

### Progress Indication

- 텍스트 대신 별 아이콘으로 진행도 표시 (★★★☆☆)
- 각 활동 완료 시 별 하나 채워짐 + 미니 펫 스프라이트 리액션
- 전체 완료 → 별 폭발 CSS 애니메이션 + 펫 레벨업 가능

### In-World Learning Game (한글 꽃밭)

홈 화면 풀밭에서 자연스럽게 복습이 일어나는 추가 학습 게임:

- **표시 조건**: `letterStats`에 학습 완료된 글자가 1개 이상일 때
- **꽃 등장**: 배운 글자가 꽃 위에 표시 (기존 `World.syncLetterFlowers()` 확장)
- **상호작용**: 펫이 꽃에 다가가면 꽃이 커지며 글자 표시 + TTS 발음 재생
- **탭 퀴즈**: 꽃 탭 시 PixiJS 오버레이로 3개 선택지 표시
  - 정답 1개 + 오답 2개 (학습 완료된 글자 중 랜덤)
  - 학습 완료 글자가 3개 미만이면 퀴즈 없이 발음만 재생
  - 맞히면: 꽃이 활짝 피며 파티클 + `letterStats` 복습 카운트 증가
  - 틀리면: 꽃이 살짝 시들 (부드럽게) + 정답 글자를 크게 보여줌 (실패 없음, 학습)

### Back Navigation

- 학습 공간에서 홈으로: 문 모양 픽셀 아이콘 (좌상단), 최소 56px 터치 타겟
- 픽셀 와이프 전환 → 펫이 왼쪽에서 걸어들어옴

## 6. Navigation & Flow

### Screen Map

```
[네이밍] → [홈 월드] ←→ [학습 공간]
              ↑
         [리포트] (부모용, 3초 길게 누르기)
```

### Naming Screen

- 첫 실행 시 알(egg) 픽셀 스프라이트가 통통 튀는 CSS 애니메이션
- 이름 입력 필드: 픽셀 스타일 테두리 (`border: 3px solid`), DungGeunMo 폰트
- 이름 입력 → 알 부화 연출 → 홈 월드로 전환
- 빈 이름 제출 방지: 입력 필드가 비어있으면 버튼 비활성화

### Screen Transitions

- **홈 → 학습:** 펫이 오른쪽으로 걸어나감 → 픽셀 와이프 전환 (CSS)
- **학습 → 홈:** 문 아이콘 탭 → 픽셀 와이프 → 펫이 왼쪽에서 걸어들어옴
- **돌봄 미니게임:** 홈 위에 팝업 오버레이 (뒤에 월드 살짝 보임, 반투명 배경)
- **픽셀 와이프 구현:** CSS `@keyframes` — 검은 사각형들이 그리드로 화면을 채웠다 사라짐 (약 0.5초)

### Navigation Principles (Non-Literate UX)

- 메뉴, 햄버거, 설정 아이콘 없음 — 아이에게 보이는 것은 펫과 4개 버튼뿐
- 부모용 리포트: 펫 이름 뱃지 3초 길게 누르기 (아이가 우연히 진입 불가)
- 뒤로가기: 항상 문 아이콘 하나로 통일
- 어디에 있든 펫이 항상 보임 (학습 중에도 미니 펫 DOM 요소)

## 7. Technical Notes

### Rendering Architecture

- **PixiJS 8.x**: 펫, 월드, 이펙트, 한글 꽃밭 퀴즈 오버레이
- **DOM + CSS**: HUD, 돌봄 바 버튼, 학습 화면 전체, 네이밍 화면, 리포트
- **경계**: PixiJS Canvas 위에 DOM이 `position: absolute`로 겹침 (기존 구조 유지)

### State Persistence

- localStorage 유지 (기존 `storage.js` 구조 변경 없음)
- 낮/밤 상태는 `Date` 기반 실시간 계산 (저장 불필요)
- 기존 사용자 데이터 마이그레이션 불필요 (스탯/진화 구조 변경 없음)

### Performance

- iPad Safari 최적화 유지
- 파티클/이펙트: 동시 최대 20개 제한 (기존 `effects.js` 참고)
- 백그라운드 탭에서 애니메이션 일시정지 (기존 로직 유지)
- 월드 오브젝트: 화면 밖 오브젝트는 렌더링 스킵
