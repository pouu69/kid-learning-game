# 타마고지 게임 고도화 설계서

**Date**: 2026-04-06
**Status**: Draft
**Target**: 5~7세 아이, iPad 브라우저

---

## 1. 핵심 전환

**Before**: 플래시카드 앱 + 다마고치 스킨 (학습과 펫이 별개)
**After**: 펫의 하루를 함께하며 자연스럽게 글자를 만나는 게임

**원칙**:
- 학습 버튼 없음. 펫의 호기심이 학습을 시작함
- 게임은 게임답게. 배운 글자가 게임 속에 자연스럽게 섞임
- 실패 없음. 틀려도 "다시 해보자~" (5세 대상)

## 2. 세션 구조

### 2.1 세션 = 하나의 이야기 (3~5분)

```
앱 오픈
  |
[펫 인사] 배운 글자로 인사 + 어제 글자 퀵 복습 (10초)
  |
[이벤트 1] 세계 이벤트 → 글자 학습 (60초)
  |
[미니게임] 배운 글자로 게임 1판 (30초)
  |
[이벤트 2] 세계 이벤트 → 글자 학습 (60초)
  |
[미니게임] 배운 글자로 게임 1판 (30초)
  |
[펫 반응] 새 능력 시연 + 아이템 획득
  |
[마무리] "내일은 뭐가 올까?" 실루엣 힌트 → 자연 종료
```

### 2.2 세션 규칙

- 하루 최대 3세션 (소프트 리밋, 강제 아님)
- 세션 사이 최소 간격 없음 (아이가 원하면 연속 가능)
- 각 세션은 다른 이벤트 (같은 날에 같은 이벤트 반복 없음)
- 이벤트 없으면 자유놀이 모드 (미니게임 + 복습)

## 3. 이벤트 시스템

### 3.1 세계 이벤트 = 커리큘럼 매핑

각 글자에 연결된 이벤트. 펫이 세계에서 무언가를 만나고 궁금해함.

**자음 이벤트:**

| 글자 | 이벤트 | 연출 | 펫 반응 |
|------|--------|------|---------|
| ㄱ | 가방이 떨어져 있다 | 가방 스프라이트 등장 | "그...가...가방!" → 메고 다님 |
| ㄴ | 나비가 날아왔다 | 나비 애니메이션 | "나비!" → 쫓아다님 |
| ��� | 다리가 나타났다 | 다리 배경 전환 | "다리!" → 건너감 |
| ㅁ | 엄마 사진 발견 | 사진 프레임 | "엄...마!" → 안아줌 |
| ㅂ | 바다가 보인다 | 파도 배경 | "바다!" → 놀람 |
| ㅅ | 사자가 방문 | 사자 캐릭터 | "사...사자!" → 숨었다 나옴 |
| ㅇ | 아기새 떨어짐 | 새 스프라이트 | "아기!" → 돌봐줌 |
| ㅈ | 자동차 지나감 | 차 이동 애니메이션 | "자동차!" → 따라감 |
| ㄹ | 라면 냄새 남 | 김 올라오는 연출 | "라면!" → 침 흘림 |

**모음 이벤트:**

| 글자 | 이벤트 | 펫 감정 |
|------|--------|---------|
| ㅏ | 펫이 크게 하품 | 입 크게 "아~" |
| ㅓ | 무언가 놀라는 소리 | "어?" 놀람 |
| ㅗ | 무지개 발견 | "오!" 감탄 |
| ㅜ | 비가 온다 | "우..." 슬픔 |
| ㅡ | 무거운 것 들기 | "으..." 힘듦 |
| ㅣ | 선물 발견 | "이!" 기쁨 |

### 3.2 이벤트 진행 흐름

```
1. 이벤트 연출 (스프라이트/배경 변화, 3초)
2. 펫 반응 ("뭐지?" 궁금해하는 표정)
3. ��레이션 "나비의 첫 소리는 ㄴ이야!"
4. 학습 활동 (trace → hunt, 또는 회전식)
5. 펫이 배운 글자로 반응 "나비!"
6. 이벤트 마무리 (나비가 펫 주위를 날아다님)
```

### 3.3 이벤트 스케줄링

- `curriculum.js`의 순서대로 이벤트 발생
- 하루에 이벤트 2~4개 (세션당 2개)
- 이벤트 간 복습 미니게임 삽입
- 모든 이벤트 소진 시 → 자유놀이 모드

## 4. 미니게임 4종

### 4.1 글자비 (Letter Rain)

**장르**: 아케이드 탭
**시간**: 15~20초
**규칙**:
- 화면 상단에서 글자가 비처럼 떨어짐
- 배운 글자(초록) = 탭해서 수집
- 안 배운 글자(빨강) = 피하기 (탭하면 "아직 안 배웠어~")
- 콤보 3개 → 펫이 춤 + 보너스 별
- 놓쳐도 패널티 없음

**구현**: PixiJS 스프라이트, 낙하 속도 점진 증가
**복습 효과**: 배운 글자 시각 인식 반복

### 4.2 펫 달리기 (Pet Runner)

**장르**: 사이드스크롤 러너
**시간**: 20~30초
**규칙**:
- 펫이 자동으로 달림 (횡스크롤)
- 목표 글자 블록 → 점프(탭)해서 수집
- 장애물 글자 → 자동 피함 (5세라 조작 최소화)
- 수집 3개마다 스피드 업 + "잘한다!"
- 거리 = 점수

**구현**: PixiJS 횡스크롤, 탭 = 점프
**복습 효과**: 글자 인식 속도 향상 (반사적 구분)

### 4.3 글자 낚시 (Letter Fishing)

**장르**: 힐링/대기
**시간**: 20초
**규칙**:
- 연못에 글자가 물고기처럼 떠다님
- "ㄴ을 잡아보자!" 음성 안내
- 목표 글자가 지나갈 때 탭
- 잡으면 "나비!" (연관 단어) + 물튀김 이펙트
- 시간 압박 없음, 여유로운 템포

**구현**: PixiJS 곡선 이동, 탭 판정
**복습 효과**: 소리-글자 연결 (청각+시각)

### 4.4 글자 요리 (Letter Cooking)

**장르**: 조합 퍼즐
**시간**: 15초
**규칙**:
- 냄비 위에 자음 2개 + 모음 2개 표시
- "가를 만들어보자!" 음성 안내
- 자음(ㄱ) 탭 → 냄비에 넣기
- 모음(ㅏ) 탭 → 냄비에 넣기
- 김이 올라오며 "가!" 완성 → 펫에게 먹이기

**구현**: 기존 SyllableFactory 재활용 + 요리 테마 스킨
**복습 효과**: 자음+모음 → 음절 조합 연습
**진입 조건**: Stage 3 이상 (자음+모음 모두 배운 후)

### 4.5 미니게임 선택 로직

```
Stage 0:     게임 없음 (통글자만)
Stage 1~2:   글자비, 펫 달리기, 글자 낚시 (랜덤 회전)
Stage 3:     글자 요리 추가
Stage 4~5:   단어 버전 (글자 대신 단어로 게임)
```

세션 내 같은 게임 연속 불가. 반드시 회전.

## 5. 펫 말하기 진화

### 5.1 대사 시스템

펫의 모든 대사는 `knownConsonants + knownVowels + completedWords` 기반.

```
배운 것 없음     → "...!" "응?"
자음 1개 (ㄱ)    → "그..."
자음+모음 (ㄱ,ㅏ) → "가!"
자음 3개+모음 2개 → "가...나...마..." (옹알이)
단어 (나비)      → 나비 이벤트 시 "나비!"
단어 5개+        → "나 배고파" "물 줘" (문장)
```

### 5.2 돌봄 요청 진화

| 배운 단어 | 배고플 때 | 졸릴 때 | 기분 나쁠 때 |
|-----------|-----------|---------|-------------|
| 없음 | 울기 (효과음) | 하품 | 풀 죽음 |
| 밥 | "밥!" | 하품 | 풀 죽음 |
| 밥,물 | "밥!" "물!" | 하품 | 풀 죽음 |
| 문장 단계 | "나 배고파~" | "졸려..." | "심심해..." |

### 5.3 인사 시스템

앱 오픈 시 펫이 배운 글자/단어로 인사:
- 첫 방문: "...!" (아직 말 못 함)
- 자음 3개: "ㄱ! ㄴ! ㄷ!" (글자 나열)
- 단어 배움: "나비! 바다!" (좋아하는 단어)
- 문장 단계: "안녕! 오늘 뭐 하자!"

## 7. 컴백 훅

### 7.1 아침 인사 (앱 오픈)

- 펫이 어제 배운 글자로 인사
- "어제 배운 ㄴ 기억나? 나...비!" (1초 복습)
- 매일 다른 인사 패턴

### 7.2 내일 힌트 (세션 종료)

- 다음 이벤트의 실루엣 표시
- "내일은 뭐가 올까?" + 동물/물건 그림자
- 아이의 호기심 자극

### 7.3 수집품 시스템

- 글자 정원 (기존 World.addLetterFlower 확장)
- 이벤트 도감: 만난 이벤트 갤러리
- 펫 옷장: 획득한 아이템 목록

### 7.4 일일 보너스

- 연속 접속 보너스: 1일=3별, 3일=5별, 7일=10별
- 매일 "오늘의 글자" 하이라이트 (랜덤 복습 대상)

## 9. 구현 우선순위

**Phase 1 (MVP)**: 세션 + 이벤트 + 펫 대사
- 세션 흐름 (이벤트→학습→마무리)
- 이벤트 시스템 (자음 9개 이벤트)
- 펫 동적 대사

**Phase 2**: 미니게임 2종
- 글자비 (가장 단순, 아케이드)
- 글자 낚시 (힐링, 대비)

**Phase 3**: 보상 + 컴백
- 별 시스템
- 펫 아이템 상점
- 일일 보너스 + 내일 힌트

**Phase 4**: 미니게임 확장
- 펫 달리기
- 글자 요리 (Stage 3 연계)
