# 타마고지 게임 고도화 설계서

**Date**: 2026-04-06
**Status**: Review Complete (3차)
**Target**: 5~7세 아이, iPad 브라우저

---

## 1. 핵심 전환

**Before**: 플래시카드 앱 + 다마고치 스킨 (학습과 펫이 별개)
**After**: 펫의 하루를 함께하며 자연스럽게 글자를 만나는 게임

**원칙**:
- 학습 버튼 없음. 펫의 호기심이 학습을 시작함
- 게임은 게임답게. 배운 글자가 게임 속에 자연스럽게 섞임
- 실패 없음. 틀려도 "다시 해보자~" (5세 대상)

---

## 2. 세션 구조

### 2.1 세션 = 하나의 이야기 (3~5분)

```
앱 오픈
  |
[펫 인사] 배운 글자로 인사 + 어제 글자 퀵 복습 (10초)
  |
[이벤트 1] 세계 이벤트 -> 새 글자 학습 (60초)
  |
[미니게임] 배운 글자 전체로 게임 1판 (30초) ← 복습 역할
  |
[이벤트 2] 세계 이벤트 -> 새 글자 학습 (60초)
  |
[미니게임] 배운 글자 전체로 게임 1판 (30초) ← 복습 역할
  |
[펫 반응] 새 능력 시연 + 아이템 획득
  |
[마무리] "내일은 뭐가 올까?" 실루엣 힌트 -> 자연 종료
```

**복습 전략**: 2단계 복습 시스템
1. **즉시 복습 (세션 내)**: 미니게임이 담당. 오늘 배운 글자 + 이전 글자 모두 등장
2. **간격 복습 (세션 간)**: 세션 시작 "펫 인사" 시 **퀵 리콜 2~3문항** (30초)
   - 기존 `_startReview`의 스페이스드 리피티션 알고리즘으로 글자 선택
   - hunt 형태의 빠른 인식 테스트 (reviewLight 모드 활용)
   - 맞추면 펫이 기뻐함, 틀리면 "다시 알려줄게~" (실패 없음)
- 미니게임의 글자 풀도 practiceLog의 interval/overdue 가중치 적용

### 2.2 세션 규칙

- 하루 최대 2세션(새 학습) + 1세션(복습 전용) = 총 3세션
- 3세션째는 새 이벤트 없이 미니게임 + 리콜 테스트만 (학습 과부하 방지)
- 세션 사이 최소 간격 없음 (아이가 원하면 연속 가능)
- 각 세션은 다른 이벤트 (같은 날에 같은 이벤트 반복 없음)
- 이벤트 없으면 자유놀이 모드 (미니게임 + 복습)

### 2.3 학습 진입점

"학습 버튼 없음" 원칙이지만, 진입점은 필요:
- **기본**: 앱 오픈 시 이벤트가 자동 시작 (펫이 "뭐지?" 하면서)
- **수동**: 펫을 탭하면 "놀자!" → 이벤트 또는 미니게임 시작
- **부모 모드**: 홈 화면 장기 터치 → 학습 진행 현황 확인 + 세션 시작
- **돌봄 연계**: 밥 먹인 후 "공부하러 갈까?" (기존 유지)

## 3. 이벤트 시스템

### 3.1 세계 이벤트 = 커리큘럼 매핑

각 글자에 연결된 이벤트. 펫이 세계에서 무언가를 만나고 궁금해함.

**자음 이벤트:**

| 글자 | 이벤트 | 연출 | 펫 반응 |
|------|--------|------|---------|
| ㄱ | 가방이 떨어져 있다 | 가방 스프라이트 등장 | "그...가...가방!" → 메고 다님 |
| ㄴ | 나비가 날아왔다 | 나비 애니메이션 | "나비!" → 쫓아다님 |
| ㄷ | 다리가 나타났다 | 다리 배경 전환 | "다리!" → 건너감 |
| ㅁ | 예쁜 모자 발견 | 모자 스프라이트 | "모...모자!" → 써보고 기뻐함 |
| ㅂ | 바다가 보인다 | 파도 배경 | "바다!" → 놀람 |
| ㅅ | 사자가 방문 | 사자 캐릭터 | "사...사자!" → 숨었다 나옴 |
| ㅇ | 아기새 떨어짐 | 새 스프라이트 | "아기!" → 돌봐줌 |
| ㅈ | 자동차 지나감 | 차 이동 애니메이션 | "자동차!" → 따라감 |
| ㄹ | 라면 냄새 남 | 김 올라오는 연출 | "라면!" → 침 흘림 |

**모음 이벤트:**

모음은 감정이 아니라 **구체적 사물+소리**로 연결 (5세가 기억할 수 있는 이미지):

| 글자 | 이벤트 | 연출 | 펫 반응 |
|------|--------|------|---------|
| ㅏ | 아이스크림 트럭 온다 | 트럭 등장 + 종소리 | "아!" → 달려감 |
| ㅓ | 어? 이상한 상자 발견 | 물음표 상자 흔들림 | "어? 뭐지?" → 열어봄 |
| ㅗ | 높은 언덕 발견! | 언덕 배경 전환 | "오! 높다!" → 올라가서 감탄 |
| ㅜ | 우산이 날아감 | 우산 날리는 바람 | "우산!" → 쫓아감 |
| ㅡ | 으르렁 소리 (곰인형) | 곰인형 흔들림 | "으!" → 깜짝 놀람 |
| ㅣ | 이빨요정 방문 | 반짝이 요정 | "이!" → 선물 받음 |

### 3.2 이벤트 진행 흐름

```
1. 이벤트 연출 (스프라이트/배경 변화, 3초)
2. 펫 반응 ("뭐지?" 궁금해하는 표정)
3. 내레이션 "나비의 첫 소리는 ㄴ이야!"
4. 학습 활동 (trace → hunt, 또는 회전식)
5. 펫이 배운 글자로 반응 "나비!"
6. 이벤트 마무리 (나비가 펫 주위를 날아다님)
```

### 3.3 자음-모음 인터리브 순서

기존 Stage 1(자음 9개) → Stage 2(모음 6개) 블록 학습을 폐기.
자음 2~3개 + 모음 1~2개를 끼워 넣어 빠르게 음절 조합을 경험하게 함.

```
Day 1: ㄱ(가방) → ㅏ(아이스크림) → "가!" 음절 완성 경험
Day 2: ㄴ(나비) → ㅏ(복습) → "나!" + 미니게임
Day 3: ㄷ(다리) → ㅓ(어? 뭐지?) → "더!" "너!"
Day 4: ㅁ(모자) → ㅗ(오! 높은 곳) → "모!" "고!"
Day 5: ㅂ(바다) → ㅜ(우산) → "부!" "무!"
Day 6: ㅅ(사자) → ㅡ(으르렁) → "스!" "그!"
Day 7: ㅇ(아기) → ㅣ(이! 선물) → "기!" "비!"
Day 8: ㅈ(자동차) → 복습 위주
Day 9: ㄹ(라면) → 복습 + 음절 조합 게임 본격 시작
```

자음을 배운 직후 모음을 배워서 음절을 만드는 성취감이 학습 지속의 핵심 동력.
기존 Stage 1/2 구분 대신 **Stage 1 = 자음+모음 인터리브** (15개), **Stage 2 = 음절 조합** 으로 재정의.

### 3.4 이벤트 스케줄링

- 인터리브 순서대로 이벤트 발생
- 세션당 이벤트 2개 + 미니게임 2판 (이벤트 사이에 삽입)
- 하루 최대 2세션 = 최대 4개 새 글자 (권장 1~2세션 = 2~3개)
- 3세션째는 **복습 전용** (새 이벤트 없이 미니게임 + 리콜 테스트만)
- 미니게임이 즉시 복습 역할 (배운 글자 전체 등장)
- 모든 이벤트 소진 시 -> 자유놀이 모드 (미니게임 무한 + 기존 hunt 복습)

## 4. 미니게임 4종

### 4.1 글자비 (Letter Rain)

**장르**: 아케이드 탭
**시간**: 15~20초
**규칙**:
- 화면 상단에서 글자가 비처럼 떨어짐
- 배운 글자(초록) = 탭해서 수집
- 안 배운 글자(빨강) = 피하기 (탭하면 "아직 안 배웠어~")
- 콤보 3개 → 펫이 춤 + 보너스 별
- 놓쳐도 패널티 없음

**구현**: PixiJS 스프라이트, 낙하 속도 점진 증가
**복습 효과**: 배운 글자 시각 인식 반복

### 4.2 글자 풍선 (Letter Balloon)

**장르**: 소리→글자 매칭
**시간**: 15~20초
**규칙**:
- 화면에 글자가 적힌 풍선 3~4개가 둥둥 떠 있음
- **소리가 먼저 재생** → "기역!" 또는 "그~" 소리
- 해당 글자 풍선 탭 → 팡! 이펙트 + 별 획득
- 다른 풍선 탭 → "이건 ㄴ이야~" (오답도 학습 기회)
- 풍선이 천천히 떠오르므로 시간 압박 낮음
- 5문제 연속 (풍선 조합이 매번 바뀜)

**글자비와의 차이**: 글자비는 시각->탭(반사), 풍선은 청각->시각 매칭(인지)
**구현**: PixiJS 스프라이트 + TTS 연동, 탭 판정 + 팡 파티클
**복습 효과**: 소리->글자 연결 (듣고 찾기)

### 4.3 글자 낚시 (Letter Fishing)

**장르**: 힐링/드래그
**시간**: 20초
**규칙**:
- 연못에 글자가 물고기처럼 떠다님
- "ㄴ을 잡아보자!" 음성 안내
- 목표 글자를 **드래그해서 바구니에 넣기** (탭이 아닌 드래그 조작)
- 잡으면 "나비!" (연관 단어) + 물튀김 이펙트 + 펫이 박수
- 다른 글자 드래그 시 → 미끄러져 돌아감 + "이건 ㄱ이야~"
- 시간 압박 없음, 여유로운 템포

**글자비/풍선과의 차이**: 글자비=탭반사, 풍선=듣고찾기, 낚시=**드래그 조작**(운동감각)
**구현**: PixiJS 곡선 이동 + 드래그 판정 + 바구니 영역
**복습 효과**: 시각 인식 + 운동감각(드래그) 멀티모달 학습

### 4.4 글자 요리 (Letter Cooking)

**장르**: 조합 퍼즐
**시간**: 15초
**규칙**:
- 냄비 위에 자음 2개 + 모음 2개 표시
- "가를 만들어보자!" 음성 안내
- 자음(ㄱ) 탭 → 냄비에 넣기
- 모음(ㅏ) 탭 → 냄비에 넣기
- 김이 올라오며 "가!" 완성 → 펫에게 먹이기

**구현**: 기존 SyllableFactory 재활용 + 요리 테마 스킨
**복습 효과**: 자음+모음 → 음절 조합 연습
**진입 조건**: Stage 3 이상 (자음+모음 모두 배운 후)

### 4.5 미니게임 선택 로직

```
Stage 0:     게임 없음 (통글자만)
Stage 1~2:   글자비, 글자 풍선, 글자 낚시 (랜덤 회전)
Stage 3:     글자 요리 추가
Stage 4~5:   단어 버전 (글자 대신 단어로 게임)
```

세션 내 같은 게임 연속 불가. 반드시 회전.

## 5. 펫 말하기 진화

### 5.1 대사 시스템

펫의 모든 대사는 `knownConsonants + knownVowels + completedWords` 기반.

```
배운 것 없음     → "...!" "응?"
자음 1개 (ㄱ)    → "그..."
자음+모음 (ㄱ,ㅏ) → "가!"
자음 3개+모음 2개 → "가...나...마..." (옹알이)
단어 (나비)      → 나비 이벤트 시 "나비!"
단어 5개+        → "나 배고파" "물 줘" (문장)
```

### 5.2 돌봄 요청 진화

| 배운 단어 | 배고플 때 | 졸릴 때 | 기분 나쁠 때 |
|-----------|-----------|---------|-------------|
| 없음 | 울기 (효과음) | 하품 | 풀 죽음 |
| 밥 | "밥!" | 하품 | 풀 죽음 |
| 밥,물 | "밥!" "물!" | 하품 | 풀 죽음 |
| 문장 단계 | "나 배고파~" | "졸려..." | "심심해..." |

### 5.3 인사 시스템

앱 오픈 시 펫이 배운 글자/단어로 인사:
- 첫 방문: "...!" (아직 말 못 함)
- 자음 3개: "ㄱ! ㄴ! ㄷ!" (글자 나열)
- 단어 배움: "나비! 바다!" (좋아하는 단어)
- 문장 단계: "안녕! 오늘 뭐 하자!"

## 6. 보상 시스템

### 6.1 별(코인)

- 학습 활동 완료: +3별
- 미니게임 클리어: +2~5별 (점수 비례)
- 일일 접속 보너스: +3별
- 마일스톤 달성: +10별

### 6.2 선물 상자 (상점 대체)

5세에게 "골라서 산다"는 지연 보상+선택 개념은 어려움. 선물 상자로 단순화:
- **10별 모으면 선물 상자 1개** 열 수 있음
- 상자를 탭하면 랜덤 아이템 1개 등장 (뽑기 형태)
- 아이템 풀: 모자, 안경, 리본, 장식, 이펙트 (등급 없음, 전부 귀여움)
- 중복 시 → "이미 있어! 다른 거 줄게~" (자동 재뽑기)
- 상자 열 때 연출: 흔들기 → 빛 → 팡! → 아이템 등장 + 펫이 착용

### 6.3 마일스톤 보상 (자동)

| 조건 | 보상 |
|------|------|
| 자음 3개 | 펫 모자 + "소리를 내기 시작했어!" |
| 자음 6개 | 펫 안경 + "거의 다 왔어!" |
| 자음 9개 완료 | 진화 + 특별 연출 |
| 모음 3개 | 펫 리본 |
| 모음 6개 완료 | 진화 + 특별 연출 |
| 음절 10개 | 펫 망토 |
| 단어 5개 | 펫 장난감 |
| 단어 15개 | 펫 최종 형태 |

## 7. 컴백 훅

### 7.1 아침 인사 (앱 오픈)

- 펫이 어제 배운 글자로 인사
- "어제 배운 ㄴ 기억나? 나...비!" (1초 복습)
- 매일 다른 인사 패턴

### 7.2 내일 힌트 (세션 종료)

- 다음 이벤트의 실루엣 표시
- "내일은 뭐가 올까?" + 동물/물건 그림자
- 아이의 호기심 자극

### 7.3 수집품 시스템

- 글자 정원 (기존 World.addLetterFlower 확장)
- 이벤트 도감: 만난 이벤트 갤러리
- 펫 옷장: 획득한 아이템 목록

### 7.4 일일 보너스

- 연속 접속 보너스: 1일=3별, 3일=5별, 7일=10별
- 매일 "오늘의 글자" 하이라이트 (랜덤 복습 대상)

## 9. 구현 우선순위

### 전환 전략

기존 학습 시스템을 유지하면서 점진적으로 이벤트 시스템으로 전환.
Phase 1 완료 후에도 기존 학습 버튼은 fallback으로 동작.

**Phase 1a (펫 대사 + 미니게임 1종)**: 가장 빠르게 체감 변화
- 펫 동적 대사 확장 (`pet.js`) — 배운 글자로 인사/요청
- 글자비 미니게임 1종 (`letter-rain.js`) — 학습 후 보상 게임으로 삽입
- 기존 학습 흐름에 미니게임 삽입: 학습 완료 → 글자비 1판 → 계속 프롬프트
- 커리큘럼 인터리브 순서 적용 (자음+모음 교차)

**Phase 1b (이벤트 시스템)**: 학습 진입 방식 전환
- 이벤트 데이터 + 스케줄러 (`events.js`)
- 이벤트 연출 (스프라이트 등장 → 펫 반응 → 학습 활동)
- 기존 `_dispatchActivity`를 이벤트 래퍼로 감싸기
- 세션 흐름 제어 (`session.js`)

**Phase 2 (미니게임 2종 추가)**:
- 글자 풍선 (탭 팝, 느긋한 템포)
- 글자 낚시 (힐링)
- 미니게임 회전 로직

**Phase 3 (보상 + 컴백)**:
- 별 시스템 + 선물 상자 (`rewards.js`)
- 일일 보너스 + 내일 힌트
- 아침 인사 (퀵 복습)

**Phase 4 (미니게임 확장 + 단어 버전)**:
- 글자 요리 (Stage 3 연계)
- Stage 4~5 단어 버전 미니게임
- 이벤트 도감, 수집품 시스템
