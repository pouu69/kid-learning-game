# 타마고지 게임 고도화 설계서

**Date**: 2026-04-06
**Status**: Draft
**Target**: 5~7세 아이, iPad 브라우저

---

## 1. 핵심 전환

**Before**: 플래시카드 앱 + 다마고치 스킨 (학습과 펫이 별개)
**After**: 펫의 하루를 함께하며 자연스럽게 글자를 만나는 게임

**원칙**:
- 학습 버튼 없음. 펫의 호기심이 학습을 시작함
- 게임은 게임답게. 배운 글자가 게임 속에 자연스럽게 섞임
- 실패 없음. 틀려도 "다시 해보자~" (5세 대상)

## 2. 세션 구조

### 2.1 세션 = 하나의 이야기 (3~5분)

```
앱 오픈
  |
[펫 인사] 배운 글자로 인사 + 어제 글자 퀵 복습 (10초)
  |
[이벤트 1] 세계 이벤트 -> 새 글자 학습 (60초)
  |
[미니게임] 배운 글자 전체로 게임 1판 (30초) ← 복습 역할
  |
[이벤트 2] 세계 이벤트 -> 새 글자 학습 (60초)
  |
[미니게임] 배운 글자 전체로 게임 1판 (30초) ← 복습 역할
  |
[펫 반응] 새 능력 시연 + 아이템 획득
  |
[마무리] "내일은 뭐가 올까?" 실루엣 힌트 -> 자연 종료
```

**복습 전략**: 별도 복습 활동 없음. 미니게임이 복습을 겸함.
- 미니게임에는 **오늘 배운 글자 + 이전에 배운 글자** 모두 등장
- 새 글자는 이벤트에서 배우고, 기존 글자는 미니게임에서 자연 반복
- 기존 `_startReview`의 스페이스드 리피티션은 미니게임 글자 선택에 활용

### 2.2 세션 규칙

- 하루 최대 3세션 (소프트 리밋, 강제 아님)
- 세션 사이 최소 간격 없음 (아이가 원하면 연속 가능)
- 각 세션은 다른 이벤트 (같은 날에 같은 이벤트 반복 없음)
- 이벤트 없으면 자유놀이 모드 (미니게임 + 복습)

### 2.3 학습 진입점

"학습 버튼 없음" 원칙이지만, 진입점은 필요:
- **기본**: 앱 오픈 시 이벤트가 자동 시작 (펫이 "뭐지?" 하면서)
- **수동**: 펫을 탭하면 "놀자!" → 이벤트 또는 미니게임 시작
- **부모 모드**: 홈 화면 장기 터치 → 학습 진행 현황 확인 + 세션 시작
- **돌봄 연계**: 밥 먹인 후 "공부하러 갈까?" (기존 유지)

## 3. 이벤트 시스템

### 3.1 세계 이벤트 = 커리큘럼 매핑

각 글자에 연결된 이벤트. 펫이 세계에서 무언가를 만나고 궁금해함.

**자음 이벤트:**

| 글자 | 이벤트 | 연출 | 펫 반응 |
|------|--------|------|---------|
| ㄱ | 가방이 떨어져 있다 | 가방 스프라이트 등장 | "그...가...가방!" → 메고 다님 |
| ㄴ | 나비가 날아왔다 | 나비 애니메이션 | "나비!" → 쫓아다님 |
| ㄷ | 다리가 나타났다 | 다리 배경 전환 | "다리!" → 건너감 |
| ㅁ | 엄마 사진 발견 | 사진 프레임 | "엄...마!" → 안아줌 |
| ㅂ | 바다가 보인다 | 파도 배경 | "바다!" → 놀람 |
| ㅅ | 사자가 방문 | 사자 캐릭터 | "사...사자!" → 숨었다 나옴 |
| ㅇ | 아기새 떨어짐 | 새 스프라이트 | "아기!" → 돌봐줌 |
| ㅈ | 자동차 지나감 | 차 이동 애니메이션 | "자동차!" → 따라감 |
| ㄹ | 라면 냄새 남 | 김 올라오는 연출 | "라면!" → 침 흘림 |

**모음 이벤트:**

모음은 감정이 아니라 **구체적 사물+소리**로 연결 (5세가 기억할 수 있는 이미지):

| 글자 | 이벤트 | 연출 | 펫 반응 |
|------|--------|------|---------|
| ㅏ | 아이스크림 트럭 온다 | 트럭 등장 + 종소리 | "아!" → 달려감 |
| ㅓ | 어항 속 물고기 발견 | 어항 스프라이트 | "어!" → 들여다봄 |
| ㅗ | 오리가 연못에 | 오리 수영 | "오리!" → 같이 놀기 |
| ㅜ | 우산이 날아감 | 우산 날리는 바람 | "우산!" → 쫓아감 |
| ㅡ | 으르렁 소리 (곰인형) | 곰인형 흔들림 | "으!" → 깜짝 놀람 |
| ㅣ | 이빨요정 방문 | 반짝이 요정 | "이!" → 선물 받음 |

### 3.2 이벤트 진행 흐름

```
1. 이벤트 연출 (스프라이트/배경 변화, 3초)
2. 펫 반응 ("뭐지?" 궁금해하는 표정)
3. 내레이션 "나비의 첫 소리는 ㄴ이야!"
4. 학습 활동 (trace → hunt, 또는 회전식)
5. 펫이 배운 글자로 반응 "나비!"
6. 이벤트 마무리 (나비가 펫 주위를 날아다님)
```

### 3.3 이벤트 스케줄링

- `curriculum.js`의 순서대로 이벤트 발생
- 세션당 이벤트 2개 + 미니게임 2판 (이벤트 사이에 삽입)
- 하루 최대 3세션 = 최대 6개 새 글자 (실제로는 2~4개가 적정)
- 미니게임이 복습 역할 (배운 글자 전체 등장)
- 모든 이벤트 소진 시 -> 자유놀이 모드 (미니게임 무한 + 기존 hunt 복습)

## 4. 미니게임 4종

### 4.1 글자비 (Letter Rain)

**장르**: 아케이드 탭
**시간**: 15~20초
**규칙**:
- 화면 상단에서 글자가 비처럼 떨어짐
- 배운 글자(초록) = 탭해서 수집
- 안 배운 글자(빨강) = 피하기 (탭하면 "아직 안 배웠어~")
- 콤보 3개 → 펫이 춤 + 보너스 별
- 놓쳐도 패널티 없음

**구현**: PixiJS 스프라이트, 낙하 속도 점진 증가
**복습 효과**: 배운 글자 시각 인식 반복

### 4.2 글자 풍선 (Letter Balloon)

**장르**: 소리→글자 매칭
**시간**: 15~20초
**규칙**:
- 화면에 글자가 적힌 풍선 3~4개가 둥둥 떠 있음
- **소리가 먼저 재생** → "기역!" 또는 "그~" 소리
- 해당 글자 풍선 탭 → 팡! 이펙트 + 별 획득
- 다른 풍선 탭 → "이건 ㄴ이야~" (오답도 학습 기회)
- 풍선이 천천히 떠오르므로 시간 압박 낮음
- 5문제 연속 (풍선 조합이 매번 바뀜)

**글자비와의 차이**: 글자비는 시각->탭(반사), 풍선은 청각->시각 매칭(인지)
**구현**: PixiJS 스프라이트 + TTS 연동, 탭 판정 + 팡 파티클
**복습 효과**: 소리->글자 연결 (듣고 찾기)

### 4.3 글자 낚시 (Letter Fishing)

**장르**: 힐링/대기
**시간**: 20초
**규칙**:
- 연못에 글자가 물고기처럼 떠다님
- "ㄴ을 잡아보자!" 음성 안내
- 목표 글자가 지나갈 때 탭
- 잡으면 "나비!" (연관 단어) + 물튀김 이펙트
- 시간 압박 없음, 여유로운 템포

**구현**: PixiJS 곡선 이동, 탭 판정
**복습 효과**: 소리-글자 연결 (청각+시각)

### 4.4 글자 요리 (Letter Cooking)

**장르**: 조합 퍼즐
**시간**: 15초
**규칙**:
- 냄비 위에 자음 2개 + 모음 2개 표시
- "가를 만들어보자!" 음성 안내
- 자음(ㄱ) 탭 → 냄비에 넣기
- 모음(ㅏ) 탭 → 냄비에 넣기
- 김이 올라오며 "가!" 완성 → 펫에게 먹이기

**구현**: 기존 SyllableFactory 재활용 + 요리 테마 스킨
**복습 효과**: 자음+모음 → 음절 조합 연습
**진입 조건**: Stage 3 이상 (자음+모음 모두 배운 후)

### 4.5 미니게임 선택 로직

```
Stage 0:     게임 없음 (통글자만)
Stage 1~2:   글자비, 글자 풍선, 글자 낚시 (랜덤 회전)
Stage 3:     글자 요리 추가
Stage 4~5:   단어 버전 (글자 대신 단어로 게임)
```

세션 내 같은 게임 연속 불가. 반드시 회전.

## 5. 펫 말하기 진화

### 5.1 대사 시스템

펫의 모든 대사는 `knownConsonants + knownVowels + completedWords` 기반.

```
배운 것 없음     → "...!" "응?"
자음 1개 (ㄱ)    → "그..."
자음+모음 (ㄱ,ㅏ) → "가!"
자음 3개+모음 2개 → "가...나...마..." (옹알이)
단어 (나비)      → 나비 이벤트 시 "나비!"
단어 5개+        → "나 배고파" "물 줘" (문장)
```

### 5.2 돌봄 요청 진화

| 배운 단어 | 배고플 때 | 졸릴 때 | 기분 나쁠 때 |
|-----------|-----------|---------|-------------|
| 없음 | 울기 (효과음) | 하품 | 풀 죽음 |
| 밥 | "밥!" | 하품 | 풀 죽음 |
| 밥,물 | "밥!" "물!" | 하품 | 풀 죽음 |
| 문장 단계 | "나 배고파~" | "졸려..." | "심심해..." |

### 5.3 인사 시스템

앱 오픈 시 펫이 배운 글자/단어로 인사:
- 첫 방문: "...!" (아직 말 못 함)
- 자음 3개: "ㄱ! ㄴ! ㄷ!" (글자 나열)
- 단어 배움: "나비! 바다!" (좋아하는 단어)
- 문장 단계: "안녕! 오늘 뭐 하자!"

## 6. 보상 시스템

### 6.1 별(코인)

- 학습 활동 완료: +3별
- 미니게임 클리어: +2~5별 (점수 비례)
- 일일 접속 보너스: +3별
- 마일스톤 달성: +10별

### 6.2 펫 아이템 상점

별로 구매:
- 모자류: 왕관(30별), 리본(15별), 고깔(10별)
- 안경류: 선글라스(20별), 하트안경(25별)
- 배경 장식: 꽃(5별), 나무(10별), 무지개(30별)
- 이펙트: 반짝임(15별), 무지개 발자국(40별)

### 6.3 마일스톤 보상 (자동)

| 조건 | 보상 |
|------|------|
| 자음 3개 | 펫 모자 + "소리를 내기 시작했어!" |
| 자음 6개 | 펫 안경 + "거의 다 왔어!" |
| 자음 9개 완료 | 진화 + 특별 연출 |
| 모음 3개 | 펫 리본 |
| 모음 6개 완료 | 진화 + 특별 연출 |
| 음절 10개 | 펫 망토 |
| 단어 5개 | 펫 장난감 |
| 단어 15개 | 펫 최종 형태 |

## 7. 컴백 훅

### 7.1 아침 인사 (앱 오픈)

- 펫이 어제 배운 글자로 인사
- "어제 배운 ㄴ 기억나? 나...비!" (1초 복습)
- 매일 다른 인사 패턴

### 7.2 내일 힌트 (세션 종료)

- 다음 이벤트의 실루엣 표시
- "내일은 뭐가 올까?" + 동물/물건 그림자
- 아이의 호기심 자극

### 7.3 수집품 시스템

- 글자 정원 (기존 World.addLetterFlower 확장)
- 이벤트 도감: 만난 이벤트 갤러리
- 펫 옷장: 획득한 아이템 목록

### 7.4 일일 보너스

- 연속 접속 보너스: 1일=3별, 3일=5별, 7일=10별
- 매일 "오늘의 글자" 하이라이트 (랜덤 복습 대상)

## 9. 구현 우선순위

### 전환 전략

기존 학습 시스템을 유지하면서 점진적으로 이벤트 시스템으로 전환.
Phase 1 완료 후에도 기존 학습 버튼은 fallback으로 동작.

**Phase 1a (펫 대사 + 미니게임 1종)**: 가장 빠르게 체감 변화
- 펫 동적 대사 시스템 (`speech.js`) — 배운 글자로 인사/요청
- 글자비 미니게임 1종 (`letter-rain.js`) — 학습 후 보상 게임으로 삽입
- 기존 학습 흐름에 미니게임 삽입: 학습 완료 → 글자비 1판 → 계속 프롬프트

**Phase 1b (이벤트 시스템)**: 학습 진입 방식 전환
- 이벤트 데이터 + 스케줄러 (`events.js`)
- 이벤트 연출 (스프라이트 등장 → 펫 반응 → 학습 활동)
- 기존 `_dispatchActivity`를 이벤트 래퍼로 감싸기
- 세션 흐름 제어 (`session.js`)

**Phase 2 (미니게임 2종 추가)**:
- 글자 풍선 (탭 팝, 느긋한 템포)
- 글자 낚시 (힐링)
- 미니게임 회전 로직

**Phase 3 (보상 + 컴백)**:
